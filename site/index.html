Circuit Split Tracker

Open disagreements among the federal courts of appeals on questions of criminal law, drawn from published opinions since 2020. Each entry shows which circuits are on which side.

Review mode. Each button opens GitHub with the request filled in. Click Create there to confirm. The site updates about two minutes later.

How this works. Each week a program searches CourtListener for new published federal appellate opinions that use circuit-split language, reads the relevant passages, and records the question and the circuits on each side. Entries marked Unreviewed were generated by software and have not been checked by a lawyer. Entries marked Reviewed have.

This is a research starting point, not legal advice. Read the opinions and confirm that a split still exists before you rely on it.
